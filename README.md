# ForgeCPP 3.1.0 · 本地账号与私人题库版

Windows 10/11 x64 本地 C++ 评测台。支持 C++11/14/17/23、测试数据 ZIP、加权评分、自定义输入、编译缓存与网页更新。无付费验证码或云评测服务。

## 首次打开：设置管理员

完整便携包请全部解压，打开 ForgeCPP-Windows 文件夹，双击 START.cmd。首次会解压编译器，需要约 1.2 GB 空间。不要直接在 ZIP 内运行，不要单独移动 START.cmd。运行期间保持启动窗口打开。不需要 WSL、Python 安装或管理员权限。

首次网页显示“设置管理员”。用户名预填 `admin`，可改为 3–32 位英文字母、数字或下划线，不区分大小写。自行设置 8–128 字符密码，完成算术验证码，即创建唯一管理员账号。**没有内置通用密码；请勿使用 GitHub、邮箱等其他网站的密码。**

请由本机所有者完成首次设置。登录页、注册页、改密页有免费加减法验证码：可换题，答案可能为负数，120 秒过期，每题只可提交一次并绑定浏览器。它是轻量防误提交/滥用手段，不是强抗机器人 CAPTCHA。账号尝试有频率限制。

首次管理员建立后，登录页可注册普通账号。注册不能指定管理员角色。

## 私人题目与管理员权限

- 普通用户：仅可通过网页/API列出、查看、编辑、导出、删除、提交评测自己的题目；只能读取自己的评测任务和历史详情。不能管理用户或安装更新。
- 管理员：可查看/编辑/删除所有题目及测试数据，查看用户列表、各用户已保存的提交源码及运行结果；可停用/启用普通账号、重置普通账号密码、查看管理日志。
- 密码使用随机盐和 PBKDF2-HMAC-SHA256（600000 次）保存，不保存明文；用户接口和管理后台均不输出密码或校验值。管理员只能重置密码，不能查原密码。
- 未提交的源码草稿保存在浏览器，按账号 ID 分开使用；不会上传给后台，因此管理员不能通过后台读取它们。历史中只会保存已提交的源码及部分诊断。
- 每账号保留最近 100 次提交；管理员列表显示所有账号最近 200 条。源码最多 256 KiB；历史输入/编译日志截断至 8192 字符，每测试点文本截断至 1024 字符。旧版记录可能只有摘要，没有源码。
- 管理日志最多保留最近 1000 条，不记录密码。
- 登录最长 8 小时；退出、改密、重置密码、停用账号会令相关会话失效。服务重启/更新后需要重新登录。Cookie 使用 HttpOnly、SameSite=Strict，服务只绑定 HTTP 回环地址。

## 从 3.0.0 升级并保留数据

先导出重要题目和源码、备份整个 data 文件夹。3.0.0 网页点击“软件更新 → 检查更新 → 安装并重启”，或者关闭 START.cmd 后将 3.1.0 应用更新包的全部文件及 static 复制到原目录，同名替换。不要删除 data、runtime、payload、toolchain。

本版采用增加字段和表的兼容迁移。迁移前保存 `data/pre-accounts-backup.db`。旧版未分配所有者的题目和历史，在首次设置管理员时全部归该管理员所有，普通注册用户不会获取这些旧题。每个普通用户有自己的一道 A+B 示例。已有浏览器草稿只为接收旧题的管理员尝试迁移一次；为防丢失，请仍先导出源码。

若你解压的是“完整包”到新目录，它是一份新的本地安装，不会自动找到其他目录的数据。不要删除原目录；优先使用原目录网页更新保留数据。

## 后台入口与密码恢复

管理员登录后点击右上角“管理后台”，包含用户、全部题目、提交记录、管理日志。管理员账号不能被停用；改自己的密码用右上角用户名 → 账户与安全。

若忘记管理员密码，请先关闭 START.cmd，在软件文件夹的命令提示符运行：

```bat
runtime\python.exe -I server.py --reset-admin-password
```

命令会要求输入并确认新密码，不回显内容。完成后重新双击 START.cmd。此命令属于有本机文件访问权限的所有者恢复机制，不是网络找回密码。

## 安全边界：不能当作不可信多租户判题网站

**账号权限不等于操作系统隔离或 C++ 安全沙箱。**这里保证的是正常网页/API的账号访问控制；评测仍执行本机原生 C++，恶意程序可能直接访问同一系统账号下的数据库、文件、网络或浏览器存储。共用同一个 Windows 账号的人也可能直接读写软件文件。不要向公网/陌生人开放，不要允许不可信用户提交程序，不要把数据库当成设备级加密保险箱。

Windows Job Object 仅提供资源及进程数限制，不能阻止读取本机文件。若需要陌生人在线注册和安全提交，必须另建隔离评测环境、独立进程账号/容器或虚拟机以及 HTTPS 服务，不能只解除 127.0.0.1 绑定。

内存显示 Windows Job 峰值提交内存，不是 RSS；超限可能表现为 RE，不保证准确识别 MLE。单评测工作进程，队列最多 8 项，每次最多 60 秒运行预算。编译缓存最多 40 个程序 / 128 MiB。

## ZIP 数据导入

编辑题目 → 导入 ZIP / 数据文件，支持同目录同前缀 `.in` 与 `.out` 或 `.ans`，可含子目录。最多 12 MiB ZIP、解压匹配文本合计 8 MiB、200 测试点/1000文件。UTF-8/BOM，Store/Deflate。拒绝路径越界、链接、加密、重复答案和缺失配对，忽略非数据文件。导入后需点“保存题目”。

## 固定更新源

发布仓库：https://github.com/ZhuyilongNB/forgecpp-updates

版本清单：https://raw.githubusercontent.com/ZhuyilongNB/forgecpp-updates/main/latest.json

只有用户点击检查/安装时连接 GitHub；不会上传账号、题目、测试数据或提交代码。更新包以 `.zip.b64` 文本发布，更新器自动解码后核对 ZIP 长度与 SHA-256，检查应用文件白名单，备份应用及 SQLite，原端口重启并健康检查，失败恢复旧应用。备份位于 data/updates/backups，成功更新保留最近三份；不自动用旧数据库覆盖当前个人数据。

SHA-256 是完整性校验，不是独立数字签名；发布账号可发布可执行软件，须保护发布账号和开启 2FA。格式 1 只支持应用白名单文件，不更新 Python 或 C++ 编译器，不允许破坏性数据库迁移。新版只有管理员能安装。

维护者先打包 `ForgeCPP-update-X.Y.Z.zip`（无顶层目录），仅包含 updater.FILES 白名单源码和文档；不能加入 data、运行时、编译器、密钥、账号库或测试数据。编码为 `.zip.b64`，先提交新版本文件，再更新 latest.json（format=1, encoding=base64, size/sha256为解码后ZIP的值，url固定本仓库main下版本文件）。不要覆盖历史版本数据文件。
